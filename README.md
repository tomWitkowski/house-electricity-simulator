# House Electricity Simulator

Interactive simulator for estimating household electricity production and consumption.

The application allows users to analyze how different factors influence the energy balance of a house, including photovoltaic production, household consumption, and potential savings.

Live app:
https://house-electricity-simulator.streamlit.app/

## Features

- Simulation of household electricity consumption
- Estimation of photovoltaic energy production
- Interactive parameter adjustments
- Visualization of energy balance
- Simple interface for quick scenario testing
